Cinder

A clay tablet from an annealing shed. The batch number is not written in digits.

A tally that has to be learned

The night shift at one glassworks marks annealing batches on clay, in a script used inside that shed. A notch in the top of the tablet is five. A pin in the lower field is one. That sum is the raw tally. A copper line across the middle means the tablet was turned on the fork, and the batch number is nine minus the raw tally. Specks along the sides are ash. They are not pins.

Nothing on the tablet is a decimal digit, and the prompt does not contain the number. The environment shows the picture, takes a reply, and returns a reward. That is the whole episode.

Three questions

Batch. One step. Reply with the batch number, turn line included. An exact digit scores 1. A neighbor scores 0.2. Anything else scores 0.

Pins. The same tablet, a different sentence. Reply with how many pins are in the lower field. Notches and the copper line do not count. The words are what change the answer.

Fork. Two tablets. The lower batch leaves the kiln first. Reply left or right. This one is for a person. The trained policy reads a single tablet.

What was trained

The policy is a small vision-language model: a short convolution reads the tablet, and the prompt is summed in as characters. The reply is one token. Training is reinforcement learning. Each step scores every legal reply on that tablet and moves toward the ones the environment scored higher. The loss never sees the correct digit as a target sentence.

Run it

python -m cinder.play

The OpenEnv server is the same loop for another program. reset returns the prompt and the picture. step takes the reply and returns the reward.

pip install -e ".[openenv]"
python -m cinder.server.app --port 8000
